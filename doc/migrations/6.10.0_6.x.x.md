# 6.10.0 to 6.x.x

## `mod_push_service_mongoosepush` configuration

The `max_http_connections` option is no longer used. Remove it from the module configuration.

Push notifications are sent asynchronously by default. To retain synchronous push notification delivery, disable the asynchronous sender:

```toml
[modules.mod_push_service_mongoosepush]
  pool_name = "mongoose_push_http"
  api_version = "v3"
  async_sender.enabled = false
```

See the [module options](../modules/mod_push_service_mongoosepush.md#options) for defaults and details.
