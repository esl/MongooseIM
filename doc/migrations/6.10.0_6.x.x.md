# 6.10.0 to 6.x.x

## `mod_push_service_mongoosepush` configuration

The `max_http_connections` option has been removed from `mod_push_service_mongoosepush` configuration. To limit the number of concurrent requests, adjust the number of workers in the HTTP connection pool used by the module.

Asynchronous push notification delivery is now supported, which should improve message processing performance. This feature is disabled by default. To enable it, add the following section to the configuration:

```toml
[modules.mod_push_service_mongoosepush]
  pool_name = "mongoose_push_http"
  api_version = "v3"

  [modules.mod_push_service_mongoosepush.async_sender]
```

See the [module options](../modules/mod_push_service_mongoosepush.md#options) for defaults and details.
