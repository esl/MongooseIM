## Removal and deprecation

The following features are removed or deprecated.

### `mod_muc_light` legacy mode removed

The `legacy_mode` option of [`mod_muc_light`](../modules/mod_muc_light.md), deprecated in 6.8.0, is now removed together with the XEP-0045 compatibility codec.

MUC Light now always speaks the protocol described in [MUC Light](../open-extensions/muc_light.md), so clients using classic MUC stanzas need to be updated.
Alternatively, enable [`mod_muc`](../modules/mod_muc.md), which implements XEP-0045 in full - but note that rooms stored by `mod_muc_light` are not visible to `mod_muc`, and there is no script migrating them.
