# 6.9.0 to 6.x.x

## Jingle push notification content

The `jingle` content source in `mod_event_pusher_push` rules now generates Jingle Message Initiation
(JMI) content instead of a regular notification with a synthetic message body. See the
[`rules.content` documentation](../modules/mod_event_pusher_push.md#modulesmod_event_pusherpushrulescontent)
for the current payload.

This changes the payload expected by custom push integrations. When using
`mod_push_service_mongoosepush`, see its
[request parameter documentation](../modules/mod_push_service_mongoosepush.md#request-parameters)
for the MongoosePush mapping and version requirement. Update MongoosePush and any custom push
integrations before upgrading MongooseIM.
